2.0.0 refactor branch architecture

monarchmoney/monarchmoney.py remains the public compatibility facade. It retains MonarchMoney.__init__, the public exception and constant identities, and the _query loader because construction spans auth and transport state and callers import or patch these symbols at this path. It assembles the purpose mixins and copies their descriptors onto MonarchMoney, preserving direct-class method lookup and common subclass/monkeypatch patterns. Authentication, saved-session persistence, GraphQL and upload transport, date helpers, and CSV conversion now live in auth.py, session.py, transport.py, goals.py, and uploads.py respectively. Other methods live in accounts, budgets, household, transactions, merchants, recurring, credit, rules, and activity modules. Auth and transport resolve ClientSession, AIOHTTPTransport, Client, and oathtool through the facade at call time so existing facade-path patches still take effect.

All 63 formerly inline GraphQL documents and the 9 existing documents live in monarchmoney/queries/<purpose>/*.graphql. _query accepts both purpose/name and the 9 legacy flat names. New operations should use a purpose path. setup.py discovers the purpose packages, and MANIFEST.in includes their documents in source distributions.

Applicable behavioral tests from the prior monolithic client and read-API files are organized under matching tests/<purpose>/ directories. tests/_fixtures.py holds their shared setup without duplicating cases. Typed-client tests live under tests/typed; cross-purpose import and signature checks live under tests/compatibility; query-resource checks live under tests/queries. Focused auth, session, and transport tests cover the newly moved implementations. Test discovery remains at 114 tests. No live financial writes are part of the suite.

Compatibility scope: recorded method signatures/defaults, public imports, exception identities, read_api's current ReadApiMixin alias, canonical GraphQL ASTs, package resources, representative return schemas, auth/session behavior, and facade-path patches to HTTP and GraphQL constructors and date helpers are protected. Python function __module__/__qualname__ and source paths now identify purpose modules. Custom monkeypatches of private rule-fragment constants no longer rewrite extracted static query resources. The pre-1.7.1 Protocol behavior of ReadApiMixin was already absent in 1.7.1 and is not restored here. A live Monarch account integration run and all third-party subclass/monkeypatch combinations have not been exercised.

This branch is groundwork only. The package version remains 1.7.1 until an explicitly requested future release process; nothing from this branch is deployed or published.
